# Funções de Data em Java

No arquivo demontracaoDataeHora.java temos as principais funções da API `java.time`, utilizando `LocalDate`.

## Conteúdos

* Criação de datas
* Consulta de dia, mês e ano
* Cálculo de idade com `Period`
* Adição e subtração de dias, semanas, meses e anos
* Comparação entre datas
* Verificação de ano bissexto
* Quantidade de dias do mês e do ano
* Primeiro e último dia do mês
